# Clusterização de Jogadores com Base em Perfil e Desempenho Físico

## Instructions

### 1. Create and Activate Venv
`python3 -m venv venv`

`source venv/bin/activate`

### 2. Install Dependencies
`pip install -r requirements.txt`

Remember to update the requirements when installing a new lib:

`pip freeze > requirements.txt`

## Structure

results can be seen in the *results.ipynb* file, the functions that generate and process the data are respectively in *clustering.py* and *injuries*.py
